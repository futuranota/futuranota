# File format tags (UI reference)

User-shared grid of format badges (TXT, DOC, PDF, MD, ZIP, CODE, PNG, JPG, IMG, VIDEO, …) for library thumbs when there is no real preview.

**Canonical code adapt target:** [`FileCard.original.tsx`](FileCard.original.tsx) — do not import Tailwind Magic into the app; recreate badges in FN CSS (`#151515`).

Use for **Skill / PDF** cells in the folder library grid and later document mini strip.

(If a PNG export of the grid is re-added to this folder, name it `file-format-tags.png`.)
