# Knowledge folder (Gina corpus)

This is Futura Nota’s **Knowledge** folder — documents and files you insert so Gina can learn.

- Prefer **inserting ready files** (.md, .sql, .txt, .pdf, …), not pasting long text in Assistance.
- Create via Documents → Knowledge → **+ new** → upload file on the knowledge document.
- **Meetings** (Assistance) are for verbal teaching / quizzes; those saves go to taught memory.

PDF: file metadata is stored; text-based files are read into the document body for Gina.
